# 📝 React Todo App

A simple yet modern Todo Application built with React.js.  
This project helps manage daily tasks with an intuitive UI and clean state management.

---

## 🚀 Features

- ➕ Add new todos
- ✔ Mark tasks as completed / pending
- 🗑 Delete tasks
- 🔍 Filter tasks:
  - All
  - Completed
  - Pending
- ⌨ Add todo using Enter key
- 🎨 Clean and modern UI design
- ⚡ Fast and responsive interface

---

## 🛠 Tech Stack

- React.js (useState, event handling, conditional rendering)
- JavaScript (ES6+)
- HTML5
- CSS3
